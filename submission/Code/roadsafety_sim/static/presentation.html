Verification System
Multi-Bus Verification
Crowd-sourced Confidence
1
🚌 First Bus Detects
Bus detects hazard, AI assigns confidence 60–98%. Event logged as UNVERIFIED.
2
📍 Second Bus Passes
Any other bus within 65 metres corroborates → status becomes PARTIALLY VERIFIED.
3
✅ Third Bus Confirms
One more verification → FULLY VERIFIED. Confidence now actionable for authorities.
4
🏛️ Authority Notified
Verified events routed to the correct authority type. Work item created in their dashboard.
Why Multi-bus Verification?
✅ Eliminates single-sensor false positives
✅ Simulates crowdsourced ground truth
✅ Scales naturally — more buses = faster verification
✅ Works offline (syncs when network returns)
📊 Verification Radius
65m
Haversine distance calculation between bus GPS and event coordinates. A passing bus within this radius automatically counts as a verification corroboration.
